# IR-Copilot

**Autonomous Earnings-Call Script, Deck & Q&A Cheat-Sheet** — a grounded, multi-agent
Investor-Relations workflow.

Given a ticker + quarter it: ingests quarterly financials and segment/operational data, benchmarks
peers, predicts the hardest questions institutional investors will ask, and drafts a compliant
earnings-call **script** + **deck outline** + **CEO/CFO Q&A cheat sheet** — with every number
traced to real defeatbeta-api evidence and a human approval gate before anything is finalized.

---

## Three operating modes (what changes at each tier)

The system is designed so that **no agent code changes** between tiers — every upgrade is a
`.env` flip and a dependency install.

| | **Dev / offline** | **Live data** | **Production (MI300X)** |
|---|---|---|---|
| **Data** | Cached real defeatbeta-api facts/news/transcripts in `mock/data/*.json` | Fresh from defeatbeta-api + HuggingFace | Same as live data |
| **Facts** | 27 grounded facts (ratios, price, income, segment/geo) from cache | Same fields, just-fetched | Same |
| **RAG** | 177 wiki chunks (transcript, financial, segment, geo, filing, news) from cache | Live-fetched | Same |
| **Embeddings** | `hash` (offline hashing trick, no download) | `sentence-transformers` `bge-base-en-v1.5` locally | `BAAI/bge-base-en-v1.5` served by **vLLM on MI300X** |
| **Sentiment** | `lexicon` (keyword scoring) | **FinBERT** (`ProsusAI/finbert`, torch) | FinBERT on MI300X |
| **LLM (drafting/analyst/verifier)** | Deterministic grounded templates — no model, no GPU | Same mock templates (or local small model) | **Llama-3.1-70B + DeepSeek LoRA** via vLLM on MI300X |
| **Vector store** | Qdrant in-memory | Qdrant in-memory or docker | Qdrant docker (`--qdrant-mode docker`) |
| **Python needed** | 3.9+ | 3.11+ (defeatbeta-api requires it) | 3.11+ |
| **Network needed** | ❌ | ✅ (HuggingFace parquet + DuckDB extension) | ✅ |
| **GPU needed** | ❌ | ❌ | ✅ AMD MI300X |

### What is and isn't AI-generated at each tier

| Component | Offline (mock LLM) | Production (vLLM) |
|---|---|---|
| Financial facts (revenue, EPS, margins…) | **Real data** from defeatbeta-api cache | **Real data** from live API |
| Revenue by segment/geography | **Real data** (breakdown cache) | **Real data** live |
| Predicted questions | **Data-driven** (segment YoY swings + peer lags + real past analyst Qs from transcripts) | Same + **fine-tuned model phrasing** |
| Earnings-call script | **Template-filled slots** (deterministic, grounded) | **LLM-phrased prose** (same grounded slot discipline) |
| Deck bullet outline | **Template-filled slots** | **LLM-phrased** |
| Q&A suggested answers | **Template-filled slots** | **LLM-phrased** |
| Number verification | **Deterministic** (same in all modes) | **Deterministic** |
| Compliance (Safe Harbor, Reg-FD lint) | **Deterministic** | **Deterministic** |

> **Key invariant:** financial numbers, segment revenue, and evidence URLs are **always real data**
> from defeatbeta-api — never generated by the LLM. The LLM only controls prose phrasing.
> This holds in all three modes.

## Quick start (offline — everything runs locally, no GPU, no network)

```bash
# 1. Clone and configure
cp .env.example .env           # defaults work as-is (USE_MOCK_DATA=true, LLM_BACKEND=mock)

# 2. Install core deps (Python 3.9+)
python3 -m pip install -r requirements.txt

# 3. Step through the notebooks  (each is self-checking with inline asserts)
PYTHONPATH=src .venv312/bin/python -m jupyter notebook notebooks/

# 4. Or start the API server (mock mode, Python 3.9+)
PYTHONPATH=src python3 -m uvicorn ir_copilot.api.server:app --port 8088
curl http://127.0.0.1:8088/health
```

> **Note:** `python3` on this machine resolves to Python 3.14 (Homebrew). Use `.venv312/bin/python`
> for all notebook execution. The server works with any 3.9+ interpreter in mock mode.

## Live data tier (Python 3.11+ required)

defeatbeta-api downloads a DuckDB extension + HuggingFace parquet on first use — network + 3.11+.

```bash
# Create a 3.12 venv (once)
python3.12 -m venv .venv312
.venv312/bin/python -m pip install -r requirements.txt -r requirements-live.txt

# Refresh the cached real data for NVDA / AMD / TSLA (~5 years)
# This populates mock/data/*.json — facts, news, transcripts, segment/geo, SEC filings
.venv312/bin/python mock/build_mock_data.py

# Live mode server (set USE_MOCK_DATA=false to query defeatbeta-api directly)
PYTHONPATH=src .venv312/bin/python -m uvicorn ir_copilot.api.server:app --reload --port 8088
```

The `mock/data/` JSON files are committed real evidence (built from defeatbeta-api). Offline mode
reads them so demos are reproducible without any external calls.

## Production tier (AMD MI300X)

```bash
# Install GPU deps (on the MI300X node only)
pip install -r requirements-gpu.txt   # vLLM (ROCm), unsloth, whisper

# Serve models (OpenAI-compatible endpoints)
vllm serve meta-llama/Llama-3.1-70B-Instruct \
     --dtype bfloat16 --port 8000     # drafting

vllm serve deepseek-ai/DeepSeek-R1-Distill-Llama-8B \
     --enable-lora --lora-modules qpredict=/models/lora_qpredict \
     --dtype bfloat16 --port 8001     # predictive analyst (fine-tuned)

vllm serve BAAI/bge-base-en-v1.5 \
     --task embed --port 8002          # embeddings

# Flip .env
USE_MOCK_DATA=false
LLM_BACKEND=vllm
EMBEDDING_BACKEND=vllm
SENTIMENT_BACKEND=finbert
QDRANT_MODE=docker
```

No code changes from offline mode. The entire `.env` flip is documented in `docs/rocm-vllm.md`.

## All capabilities as HTTP API

```
GET  /health                         — status + active backend config
GET  /api/facts/{ticker}             — 27 grounded financial facts with provenance
GET  /api/sentiment/{ticker}         — net score + themes + cited news sources
GET  /api/competitor/{ticker}        — peer comparison leads/lags (grounded)
GET  /api/questions/{ticker}         — predicted hard questions with evidence URLs
GET  /api/draft/{ticker}             — script + deck + Q&A + verification + compliance
GET  /api/wiki/search?q=&ticker=&k=  — BM25-blend retrieval across all 6 doc types
GET  /api/run/{ticker}/stream        — SSE stream of agent updates → pause at human gate
POST /api/run/{ticker}/resume        — resume with human approve/edit
POST /copilotkit                     — CopilotKit AG-UI (LangGraph CoAgent for React UI)
```

```bash
# Stream the full run, review, and approve
curl -N http://127.0.0.1:8088/api/run/NVDA/stream
curl -X POST http://127.0.0.1:8088/api/run/NVDA/resume \
     -H 'Content-Type: application/json' \
     -d '{"thread_id":"NVDA-FY2026Q2","decision":"approve"}'
```

## Configuration (`.env`)

| Variable | Values | Notes |
|---|---|---|
| `USE_MOCK_DATA` | `true` / `false` | `true` = read `mock/data/*.json`; `false` = live defeatbeta-api |
| `LLM_BACKEND` | `mock` / `vllm` | `mock` = deterministic templates; `vllm` = MI300X endpoints |
| `EMBEDDING_BACKEND` | `hash` / `sentence-transformers` / `vllm` | BM25 alpha auto-adjusts per backend |
| `SENTIMENT_BACKEND` | `finbert` / `lexicon` | finbert needs torch; auto-falls back to lexicon |
| `QDRANT_MODE` | `memory` / `docker` / `local` | docker falls back to memory if unreachable |
| `DEMO_TICKER` / `PEER_TICKERS` | `NVDA` / `AMD,TSLA` | tickers with cached real data |

## Repository layout

```
src/ir_copilot/
  config.py          settings from .env
  facts.py           Financial Fact Store + slot renderer + numeric verifier
  live.py            defeatbeta-api fetchers (facts, segments, transcripts, filings, news)
  mockdata.py        reader for mock/data/*.json
  corpus.py          routes offline→mockdata or live→live.py; exposes wiki_chunks / signals
  cache.py           SQLite persistence (no parquet/duckdb)
  embeddings.py      hash | sentence-transformers | vllm
  vectorstore.py     Qdrant wiki + BM25Reranker
  llm.py             mock | vllm chat clients
  service.py         all capabilities as Python functions (used by API + notebooks)
  graph.py           LangGraph StateGraph + HITL interrupt
  agents/            sentiment · competitor · predictive · drafting · verify
  api/server.py      FastAPI + CopilotKit CoAgent

mock/
  build_mock_data.py  rebuild real cache (needs .venv312 + network)
  data/NVDA.json      27 facts + 60 wiki chunks + 12 signals (real evidence)
  data/AMD.json       23 facts + 57 wiki chunks + 2 signals
  data/TSLA.json      26 facts + 59 wiki chunks + 3 signals

notebooks/
  01_data_extraction_fact_store.ipynb
  02_wiki_ingestion_qdrant.ipynb     ← multimodal RAG + BM25 reranker
  03_market_sentiment.ipynb
  04_competitor_comparison.ipynb
  05_predictive_analyst.ipynb        ← segment signals + peer lags + real analyst Qs
  06_drafting_and_grounding.ipynb    ← Safe Harbor + compliance + grounding verifier
  07_langgraph_orchestration.ipynb   ← full pipeline + HITL
  08_finetuning_unsloth.ipynb        ← GPU-only recipe (MI300X)
```

Persistence: **SQLite** (`artifacts/ir_copilot.sqlite`, git-ignored). Fine-tuning (Unsloth, the
critical hackathon feature) runs on the MI300X — `notebooks/08`, `docs/finetuning.md`.
